## Project Skills

This project defines five specialized engineering skills in `.claude/skills/`:

- `add-icon`: Add a custom SVG icon following the 24x24 single-file specification.
- `new-feature-module`: Scaffold a new feature domain with contracts, models, and public surface.
- `use-design-tokens`: Reference and map semantic design tokens across themes and reader surfaces.
- `ui-review`: Inspect responsive screenshots and verify WCAG contrast and layout hierarchy.
- `add-api-contract`: Create a new Zod contract, type definitions, and mock/http adapters.
